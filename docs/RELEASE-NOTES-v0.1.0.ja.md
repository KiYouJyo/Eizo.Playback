# Eizo.Playback v0.1.0 — 初回公開リリース

- Eizo UI から独立した再生抽象化レイヤーを導入し、メディアのオープン、再生/一時停止/停止、シーク、音量、再生速度、状態・エラーイベントを統一しました。
- LibVLC ベースの Windows バックエンドを提供し、LibVLCSharp の型をアダプター層に隔離しています。
- WinUI 3 用の `PlaybackView` と D3D11 SwapChain 映像出力を実装しました。
- 音声・映像・字幕トラックの検出と切り替え、外部字幕、字幕/音声遅延、タイトル・チャプター操作に対応します。
- 再生能力・ランタイム診断を提供しつつ、ローカル入力パスなどを診断情報へ露出しない設計です。
- 4 つの NuGet パッケージを Release 資産として公開します。
- SHA-256 一覧を同梱し、CI で Release ビルド、テスト、パッケージ内容を検証します。

v0.1.0 は Eizo.Playback の最初の安定統合ベースラインです。Eizo v0.2.1 はこのバージョンを固定して使用します。
